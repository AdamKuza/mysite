# Адамъ Кузнецовъ — персональный сайтъ

Откройте index.html в браузере. Файлы разделены: index.html — разметка и SVG; styles.css — стили; app.js — JavaScript; src/fonts — шрифты. Держите их в одной папке с сохранением структуры. Для публикации загрузите всю папку, а не один HTML. Интернет и сборщик для просмотра не нужны.

В каждой сцене четыре верёвки: Петербург, Москва, Нью-Йорк и Мекка. Три ведут напрямую в остальные сцены; верёвка текущей сцены приглушена и недоступна. Нажмите на кисточку или потяните её вниз и отпустите. Раскачивание в стороны не переключает сцену. Стрелка вниз, Enter и пробел работают с клавиатуры. Назначения верёвок постоянны во всех сценах.

Сцены занимают ровно высоту окна (100dvh), без прокрутки. Расположение текста и иллюстраций зависит от ширины и высоты окна. Без JavaScript сцены идут последовательно.

Оптимизация: дождь и снег используют заранее построенные SVG-слои с CSS transform, без изменения контуров каждый кадр. Скрытые сцены и анимации фоновой вкладки приостанавливаются. Физика верёвок работает при взаимодействии и засыпает в покое. В Мекке меняется сила теплового искажения, а не частота генерации шума.

Исходники в src. template.html — текст и разметка; viewport.css — размеры окна; weather.js / weather.css — осадки; book.js / rope.js — переходы и физика. Шрифты и лицензии находятся в src/fonts. Источник CC0-контура статуи: src/references/LICENSE.md.

Править готовую версию можно в index.html, styles.css и app.js. Команда build.ps1 пересобирает эти файлы из исходников src и перезаписывает ручные правки готовой версии.

Сборка и проверка:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
    powershell -NoProfile -ExecutionPolicy Bypass -File .\verify.ps1

qa/rope-transition-check.mjs проверяет координацию переходов, физику, клики и раскачивание на управляемых часах. qa/performance-results.json содержит текущие измерения встроенного браузера Chromium. Более ранние отчёты Firefox в qa относятся к предыдущим версиям и не подтверждают текущую производительность Firefox.

Пасхалка: нажмите розу ветров справа в шапке Петербурга 10 раз. На её месте появится верёвка; потяните её вниз, чтобы открыть секретную сцену. Разблокировка хранится до перезагрузки страницы. Из секретной сцены доступны все четыре обычные верёвки.

Держатели верёвок в Москве и Мекке следуют векторному контуру арки. При переходе весь узел складывается вместе с рамкой, а локальная физика верёвки сохраняется. Позиции и центры вращения измеряются только при смене сцены и размера окна.
